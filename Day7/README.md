# SnapShare Scaling Plan

## Description
This project explains how SnapShare, a photo-sharing application, can scale to support millions of users, photo uploads, and feed views.

## Main Topics
- Traffic and storage calculations
- Read-heavy and write-heavy workloads
- System architecture
- Image storage using object storage and a CDN
- Photo upload and thumbnail generation workflow
- System design trade-offs

## Technologies and Components
- Application servers
- Load balancer
- Cache
- Database and read replica
- Object storage
- Message queue and thumbnail workers
- Content Delivery Network (CDN)

## Purpose
The goal is to understand how to design a scalable, reliable, and efficient photo-sharing system.
